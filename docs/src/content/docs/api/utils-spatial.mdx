##### `query_radius`

Find all points within radius of center.

Args:
    center: Center position (3D)
    radius: Search radius
    return_distances: Whether to return distances

Returns:
    Indices of points within radius, and optionally their distances

```python
def query_radius(center: np.ndarray, radius: float, return_distances: bool = False) -> Tuple[np.ndarray, Optional[np.ndarray]]
```

**Parameters:**

- `center` (`np.ndarray`)
- `radius` (`float`)
- `return_distances` (`bool`) — default: `False`
