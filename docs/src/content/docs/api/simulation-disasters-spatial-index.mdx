# Spatial Index

**Module:** `great_silence.simulation.disasters.spatial_index`

Spatial indexing for disaster events.

Provides O(k*m) spatial queries using 3D voxel grid.

```python
from great_silence.simulation.disasters.spatial_index import ...
```

##### `query_spatial`

Query disasters within radius of center.

Complexity: O(k * m) where k = touched voxels, m = disasters/voxel

Args:
    center: (3,) query center in kpc
    radius_kpc: Search radius

Returns:
    List of disasters within radius

```python
def query_spatial(center: np.ndarray, radius_kpc: float) -> List[DisasterBinary]
```

**Parameters:**

- `center` (`np.ndarray`)
- `radius_kpc` (`float`)

---

##### `query_temporal`

Query disasters in time window.

Uses binary search on sorted times.

Args:
    time_start: Window start (Myr)
    time_end: Window end (Myr)

Returns:
    List of disasters in window

```python
def query_temporal(time_start: float, time_end: float) -> List[DisasterBinary]
```

**Parameters:**

- `time_start` (`float`)
- `time_end` (`float`)
