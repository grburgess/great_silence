## Where is everybody?

The Milky Way contains 100-400 billion stars. If even a tiny fraction develop intelligent life, 
the galaxy should be teeming with civilizations. Yet we see... nothing. **Only silence.**

**Great Silence** is a physics-based simulation framework that lets you explore solutions 
to the Fermi Paradox by modeling:

<CardGrid stagger>
  <Card title="Realistic Galaxy" icon="star">
    Hernquist bulge, exponential disk, spiral arms, and gravitational stellar motion
  </Card>
  <Card title="Civilization Emergence" icon="rocket">
    Drake equation with configurable parameters and probabilistic emergence
  </Card>
  <Card title="Interstellar Expansion" icon="seti">
    Self-replicating probes with relativistic travel times and wavefront propagation
  </Card>
  <Card title="Astrophysical Hazards" icon="warning">
    Supernovae, gamma-ray bursts, and neutron star mergers as extinction events
  </Card>
  <Card title="Great Filter Scenarios" icon="bars">
    Crisis peaks at technological transitions based on Kardashev scale
  </Card>
  <Card title="Monte Carlo Analysis" icon="random">
    Statistical ensembles across parameter space for robust conclusions
  </Card>
</CardGrid>

## Quick Start

<Tabs>
  <TabItem label="Python API">
```python
from great_silence import GalaxySimulation, SimulationConfig

# Use an optimistic preset
config = SimulationConfig.with_preset("optimistic")
config.simulation.save_snapshots = True

# Run simulation
sim = GalaxySimulation(config, seed=42)
sim.run(verbose=True)

# Get results
stats = sim.get_statistics()
print(f"Total civilizations emerged: {stats['total_civilizations']}")
print(f"Active at end: {stats['active_civilizations']}")
```
  </TabItem>
  <TabItem label="CLI">
```bash
# Quick test run with visualization
great-silence --quick --visualize

# Full simulation with custom config
great-silence --config my_scenario.yaml --output results/

# Monte Carlo ensemble (100 realizations)
great-silence --mode monte-carlo --output monte_carlo/
```
  </TabItem>
  <TabItem label="Web App">
```bash
# Launch interactive web interface
great-silence-webapp --port 8080
```

Then open **http://localhost:8080** for the interactive dashboard with preset scenario selector, real-time simulation progress, embedded 3D visualization, and configuration management.
  </TabItem>
</Tabs>

## Scientific Foundations

| Concept | Description |
|---------|-------------|
| **Drake Equation** | N = R★ × fp × ne × fl × fi × fc × L — estimates detectable civilizations |
| **Kardashev Scale** | Civilization energy usage: Type I (planet), II (star), III (galaxy) |
| **Great Filter** | Hypothetical barrier preventing civilizations from becoming spacefaring |
| **Fermi Paradox** | The contradiction between lack of evidence and high probability estimates |
